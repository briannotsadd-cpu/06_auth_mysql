# 06_auth_mysql — Login/Register ด้วย Next.js + MySQL (DIT205 assignment 07)

ผู้จัดทำ: กฤตภาส จางศิริ (Krittaphas Changsiri) 6806886

## รันบนเครื่อง
1. ติดตั้ง MySQL แล้วรัน schema.sql
2. คัดลอก .env.example เป็น .env.local แล้วใส่ค่าจริง
3. npm install แล้ว npm run dev เปิด http://localhost:3000

## Environment variables
DB_HOST, DB_PORT, DB_USERNAME, DB_PASSWORD, DB_DATABASE, DB_SSL (true เมื่อใช้ TiDB Cloud), JWT_SECRET
